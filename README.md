# CISC 101 — Research Paper Summarizer (Group 82)

This repository contains our final project for **Problem Set 3 (PS3)** in CISC 101.  
The project implements a **Research Paper Summarizer** that uses modular prompting, guardrails, specification design, and long-text handling strategies to summarize research papers such as *Attention Is All You Need*.

## Modules Overview

### **01_intake_and_setup.md**
Validates inputs, normalizes `section_list`, detects missing/short sections, and prepares chunking for long papers.

### **02_section_loop.md**  
(Updated for Task 3)  
Loops through each section, applies guardrails, and produces:
- Short summaries (1–2 sentences)  
- Detailed summaries (paragraph + 3–5 bullet points)  
- Warnings for short/missing sections  
- Glossary candidates  

### **03_guardrails.md**  
(Updated for Task 3)  
Implements:
- Strict evidence mode  
- “Use only provided text” enforcement  
- Standardized warnings  
- Detection of hallucination risks  
- Section isolation and chunking integrity  

### **04_rendering_and_refinement.md**
Assembles the final six output sections:
1. Paper Summary  
2. Section-by-Section Table  
3. Expert Summary  
4. Lay Summary  
5. Mini-Glossary  
6. Checks & Warnings  

### **05_citation_extractor.md**
Student-created module #1: extracts references and citations.

### **06_equation_figure_explainer.md**
Student-created module #2: identifies equations and figures and produces expert/lay explanations.
