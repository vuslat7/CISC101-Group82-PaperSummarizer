Module 04 – Rendering & Refinement

Assemble required headings:

Order: Paper Summary, Section-by-Section Table, Expert Summary, Lay Summary, Mini-Glossary, Checks & Warnings.

Paper Summary:

Content: 1–3 paragraphs capturing the core problem, approach, results, and contributions using allowed evidence mode.

Section-by-Section Table:

Columns: Section | Summary | Key Ideas | Warnings.

Population: Draw from Module 02 artifacts. If a section is missing/empty, table row includes the standardized warning and blank summary/key ideas.

Expert Summary:

Audience: Technical explanation aligned with the paper’s terminology and assumptions.

Evidence mode: Respect strict/normal rules; avoid external context.

Lay Summary:

Audience: Non-expert; simplify jargon while preserving accuracy.

Clarity: Use analogies only if grounded in explicit text; otherwise avoid.

Mini-Glossary:

Scope: 5–15 terms explicitly present in the text.

Definitions: Concise, section-grounded, and consistent with evidence mode.

Checks & Warnings:

Include: Missing sections, empty sections, very short sections, strict evidence limitations, chunking notes, section alignment anomalies, length truncation notes (if max_length impacted content).

Formatting validation:

Headings: Exact names.

Table: Valid Markdown table syntax.

Bullets: Only where permitted (detailed mode and glossary).

Language/length: Apply language and max_length constraints.
