Module 06 – Student Module: Equation and figure explainer

Detect equations/figures:

Equations: Inline/display math markers and definitional statements.

Figures/Tables: Captions, references (e.g., “Figure 1”), and described content within the text.

Explain using paper text only:

Equations: Summarize stated roles, variables, and relationships if explicitly defined.

Figures: Explain what the figure illustrates strictly from captions and accompanying text.

Add notes for glossary and warnings:

Glossary feed: Extract defined terms (symbols, layers, mechanisms) for # Mini-Glossary.

Checks & Warnings: If an equation/figure is referenced but not described, add a note indicating limited context; in strict mode, use the standardized strict-mode message for that section’s summary if detail is insufficient.

Integrity:

Section-local: Keep explanations bound to the section where the equation/figure is defined or discussed.

No speculation: Do not infer figure contents or variable meanings beyond explicit text.
